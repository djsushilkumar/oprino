# Oprino Architecture Decision Records (ADR)

This directory serves as the canonical index and archive for all Architecture Decision Records for the Oprino platform.

Every architectural decision is evaluated against the **Phase 00 Approved Product Baseline** ([`docs/product/OPRINO-MASTER-PRD.md`](file:///workspace/oprino/docs/product/OPRINO-MASTER-PRD.md)), field operational realities for SMBs (5–500 employees, optimized for 10–200), Android/iOS parity, zero off-duty tracking, and sustainable unit economics.

## Phase 01A Architectural Synthesis

All 20 ADRs together establish a cohesive, modern 2026 technology foundation:
1. **Polyglot Contract Safety:** OpenAPI 3.1 serves as the authoritative cross-language contract boundary between Fastify TypeScript routes and Flutter Dart clients (`openapi-generator-cli dart-dio`).
2. **Duty-Hours-Only Privacy Enforcement:** Guaranteed at OS service acquisition level, mobile local queue level, server-side ingest validation, and automated 30-day telemetry partition drops.
3. **Multi-Tenant Isolation by Default:** 5-stage zero-trust verification at the gateway paired with PostgreSQL row-level security scoped per transaction.
4. **Offline Resilience:** Drift + SQLite outbox queue on mobile with client-generated UUIDs, separate from native Transistor geolocation buffers.
5. **Sustainable Unit Economics:** Cloud infrastructure modeled at ~$0.40/user/month at scale, preserving 87%–90%+ gross margins.
